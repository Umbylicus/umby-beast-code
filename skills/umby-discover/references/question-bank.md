# Surgical Discovery Question Bank

Select **only 3 to 5 questions** whose answers are genuinely missing from the user's prompt and workspace. Always include concrete options with a `(Recommended)` first choice tailored to their domain.

---

## Core Questions (Greenfield Websites & Apps)

### Q1. Primary Visitor & Single Conversion Action
> "When a skeptical visitor lands on the page, what is the single primary action they should take within 60 seconds?"
- *(Recommended — tailor to product)* e.g., `Try an interactive product demo right in the hero, then start free`
- `Book a qualified sales / architecture call (high-ticket B2B)`
- `Purchase / add flagship product directly to bag (self-serve commerce)`
- `Join waitlist / read technical thesis (pre-launch positioning)`

### Q2. Aesthetic Archetype & Visual Atmosphere
> "Which visual direction best matches the brand's status and audience?"
- *(Recommended — pick best match from `aesthetic-archetypes.md`)* e.g., `Swiss Editorial Light (warm paper surfaces, sharp serif+grotesk contrast, institutional authority like Stripe Press / Mercury)`
- `Precision Dark Monolith (obsidian surfaces, 1px specular hairlines, electric single accent like Linear / Raycast)`
- `High-Key Hardware Cinema (alternating crisp daylight & deep media stages, Apple flagship pacing)`
- `Warm Tactile Boutique (linen/stone tones, crisp photography-first layout, architectural 2px corners like Aesop / Rimowa)`

### Q3. Proof Assets & Content Honesty
> "What real proof do we have today so we never ship fake AI filler metrics or made-up quotes?"
- *(Recommended)* `Build an interactive live product simulation / calculator + real technical mechanics (no fake logos or user counts)`
- `I will provide real customer metrics, logos, pricing, or photography right now`
- `Use clearly marked, realistic domain data structures that I can swap via a single config file before launch`

### Q4. Scope of Pass 1 & Technical Stack
> "What should we ship end-to-end in this first build?"
- *(Recommended)* `Complete flagship homepage + primary conversion flow (e.g., interactive pricing / checkout drawer / signup) in Next.js + Tailwind`
- `Ultra-fast multi-page marketing + blog/docs architecture in Astro (zero unnecessary client JS)`
- `Full application shell + core authenticated dashboard workflow`

## Specialized Questions by Domain

### For E-Commerce Storefronts
- **Catalog Shape:** Single hero flagship product (Apple/Eight Sleep narrative funnel) vs. curated 5–30 SKU boutique vs. 100+ SKU faceted catalog (Amazon/SSENSE instant filter architecture)?
- **Checkout Backend:** Shopify Storefront API headless, Stripe Checkout direct, Medusa self-hosted, or front-end storefront with local persisted bag state first?

### For Brownfield Website Updates
- **Sacred Equity vs. Fair Game:** Should we preserve your existing logo, URL structure, and brand primary color while overhauling typography, layout, copy, and components—or is this a full visual rebrand?
- **Risk Boundary:** Are there live forms, analytics tags, CMS webhooks, or SEO-ranking blog routes that must remain byte-compatible in URL and payload?
