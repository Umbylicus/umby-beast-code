# Genre benchmarks

Starting points for the benchmark table. These are commonly cited opinions, not measurements. Check a pick against a current source when you have web access, prefer the comparables the user named, and say "opinion" in the table when you could not source it.

A benchmark is a quality bar for one aspect. Study what makes it good at that aspect and aim for the same standard in an original game. Never copy its names, characters, art, music, levels, or look.

| Genre | Aspect | Often cited as the bar |
| :--- | :--- | :--- |
| Platformer | Movement feel | Celeste (its developers have written about the forgiveness windows) |
| Platformer | Feedback | Super Meat Boy, Hollow Knight |
| Platformer | Level design | Super Mario Bros. 3, Mega Man |
| Top-down shooter | Feedback and screen shake | Nuclear Throne and other Vlambeer games |
| Top-down shooter | Loop and escalation | Vampire Survivors |
| Top-down shooter | Feedback density | Enter the Gungeon |
| Puzzle | Clarity and ramp | Tetris |
| Puzzle | Teaching through play | Portal, Baba Is You |
| Roguelike | Run structure and onboarding | Hades |
| Roguelike | Item variety | The Binding of Isaac |
| Racing | Input precision | Trackmania |
| Racing | Readable items and catch-up | Mario Kart 8 |
| Tower defense | Readable waves and upgrade paths | Kingdom Rush |
| Tower defense | Upgrade depth | Bloons TD 6 |
| Idle or clicker | Progression curve | Cookie Clicker |
| Idle or clicker | Decisions inside a number loop | Universal Paperclips |
| Deck-builder | Run structure and synergy | Slay the Spire |
| Deck-builder | Scoring clarity and fast feedback | Balatro |

For a genre not listed, ask the user which games it should feel like, then pick per aspect from those and from current "best of genre" coverage.

Two general references on feel and feedback apply to every genre: the "Juice It or Lose It" talk by Martin Jonasson and Petri Purho, and Steve Swink's book *Game Feel*.
