# Category Blueprint 3: B2B SaaS, AI Infrastructure & Product-Led Marketing (Stripe + Linear Caliber)

## 1. Replace Static Dashboard JPEGs With Live Micro-Sandboxes

The #1 differentiator between a $5B software site (Stripe, Linear, Dub, Clerk, Resend) and a template wrapper is that **you can touch the product inside the hero**:
- Build a real, self-contained, deterministic React/HTML miniature of the core workflow right inside the hero or Beat 2 (e.g., an interactive API payload builder that updates a live webhook log; a live query bar that filters 8 realistic rows in `<20ms`; a slider that recalculates real unit economics).
- Pre-populate with crisp, domain-authentic sample records (real merchant categories, realistic latency numbers like `18.4ms`, valid ISO timestamps—never `Test Item 1`, `foo`, `bar`).

## 2. Non-Formulaic Section Architecture

1. **Hero:** Sharp mechanism-driven H1 (`<=9` words) + 1–2 sentence concrete subhead (`<=28` words) + Primary CTA (`Start building` / `Open live sandbox`) + quiet Secondary CTA (`Read docs` / `Book architecture review`) + Interactive Product Stage.
2. **Credibility Strip (Only When Real):** Monochrome logos at controlled `20px–24px` optical height, or concrete engineering proof (`SOC2 Type II`, `99.99% historical uptime`, `Open-source MIT core` with real repo link). If pre-launch with zero customers, **skip the logo strip entirely** rather than inventing fake company names.
3. **Workflow Deep-Dive (Split Sticky Architecture):** Left column narrates 3 real technical steps; right stage morphs cleanly through the exact code/UI state for each step.
4. **Developer / Integration Ergonomics (If Technical):** Tabbed Shiki code block (`TypeScript | Python | cURL`) with copy button + live response preview side by side.
5. **Transparent Pricing Architecture:**
   - Monthly / Annual toggle updating prices smoothly with `tabular-nums` (stating exact savings math, e.g., `Save 20% on annual billing`, never vague `"Best Value!!"` badges).
   - Highlight differential capabilities per tier rather than repeating the same 12 checkmarks across all three columns.
6. **Direct Bottom Conversion Band:** Restate the core value in one fresh sentence + immediate action without repeating the hero word-for-word.
