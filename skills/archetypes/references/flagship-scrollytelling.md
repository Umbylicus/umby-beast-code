# Category Blueprint 1: Flagship Product & Hardware Storytelling (Apple Caliber)

## Section Pacing Architecture (7-Beat Arc)

1. **Beat 1 — Sticky Sub-Nav + Iconic Hero Stage:**
   - Compact `48px` translucent sticky product bar (`Product Name` on left; `Overview | Specs | Compare` + compact `Buy / Pre-order` pill on right) appearing once main nav scrolls past.
   - Tight, declarative hero lockup (`<=7` words) + physical/interactive centerpiece media + price/availability anchor (`From $299` or `Ships Nov 24`).
2. **Beat 2 — High-Contrast Highlight Reel / Interactive Chapter Tabs:**
   - Large concentric `24px`-radius media stage (`aspect-[16/9]` desktop, `aspect-[4/5]` mobile) with pill chapter controls allowing immediate click-through OR scroll progression.
3. **Beat 3 — Contrast Shift into Deep Dive #1 (Macro Engineering):**
   - Switch surface polarity (e.g., daylight `#f5f5f7` -> obsidian `#0a0a0c`).
   - Pair one close-up diagram/anatomy breakdown with 2–3 stark numeric callouts (`14.2 hrs`, `0.4 mm`, `3.8x`) set at `clamp(2.25rem, 4.5vw, 4rem)` with `13px` concrete explanations underneath.
4. **Beat 4 — Interactive Comparison / Mode Toggle:**
   - Let the user drag a before/after loupe, switch finish colors (`Anodized Silver`, `Matte Obsidian`, `Signal Orange`) updating real assets instantly, or toggle acoustic/thermal overlays.
5. **Beat 5 — Asymmetric Bento Proof Grid (Non-Uniform Cells):**
   - A 12-column asymmetric bento (`7 + 5` top row, `4 + 4 + 4` or `5 + 7` bottom row) where every cell holds a bespoke micro-diagram, metric chart, or material closeup—**never** small Lucide icons floating in empty boxes.
6. **Beat 6 — Architectural Specification Table:**
   - Clean horizontal `1px` hairline rows grouping dimensions, materials, compatibility, what's in the box, and warranty in crisp scannable columns.
7. **Beat 7 — Frictionless Configuration / Purchase Anchor:**
   - Direct variant selector + delivery transparency + clean FAQ accordion addressing the top 5 buyer objections.
